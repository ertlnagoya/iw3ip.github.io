# 授業ガイド

!!! abstract "このページの位置付け"
    講師・TA 向けの「ワークショップ」の章のページです。受講者は [学習ロードマップ（初級者向け）](roadmap.md) から読み始めてください。

この章では、IW3IP の教材を授業や演習でどのように扱うかを整理します。

個々のサンプルを順に動かすだけでも学べますが、授業では「どこで全体像を示し、どこで手を動かし、どこで振り返るか」を先に決めておくと進行しやすくなります。

## 想定対象

- 情報系学部の学部2-4年生
- 「ネットワーク」「Web/API」「データベース」「プログラミング」の基礎を履修中または履修済み

## この教材で身につくこと

- 分散データ共有の基本構成を説明できる
- Consent VC にもとづくアクセス判定を理解できる
- オンチェーン/オフチェーン分離の設計意図を理解できる
- 実験ログを根拠に検証結果を報告できる

## 学習の進め方

基本的な学習とハンズオンは、サイト内の流れに沿って進められます。

- サイト内で扱う内容:
  - 基本用語
  - システム全体像
  - 最短起動
  - Hands-on 実行
  - 結果の読み取り
- 外部資料が役立つ場面:
  - 仕組みの詳細を知りたいとき
  - レポートや卒論の背景調査をするとき
  - 標準仕様の原典を確認したいとき

授業では、サイト内の説明で前提をそろえてから外部資料に進む方が効率的です。

## 演習に使えるコマ数別の構成

1 コマを 90 分として、演習に使えるコマ数ごとの必修ページの組み合わせです。時間は各ページの冒頭にある所要時間の合計です。事前準備（ツールのインストール）は、演習の前に各自で済ませる前提です。ページの順は、受講者向けの [学習ロードマップ（初級者向け）](roadmap.md) の最短学習パス (事前準備 → 実機なしで一連を動かす → 最短起動 → Part 1 の 1.2 → 1.3) とおおむね同じです。1 コマと 3 コマの構成では、1.2 に [Home Assistant のデータを取り込む (HA SSI Publisher)](../hands-on/ha-ssi-publisher.md) を使うため、最短起動を 1.2 のあと (3 コマの構成では 2 回目の最初) に行います。

| 使えるコマ数 | 取り上げるページ | ねらい |
|---|---|---|
| 1 コマ | [実機なしで一連を動かす (HA Demo Simulator)](../hands-on/ha-demo-simulator.md)（約 20 分）→ [Home Assistant のデータを取り込む (HA SSI Publisher)](../hands-on/ha-ssi-publisher.md)（約 45 分）→ ふりかえり | 同意にもとづく `allow` / `deny` と監査ログを確認する |

15 コマの計画では、10〜12 回の「検証・比較」に Part 3 の [地域安全アシスタントを動かす](../hands-on/regional-safety-assistant.md)（約 60 分）と [AI に手順を考えさせる (LLM Planner)](../hands-on/llm-planner.md)（約 60 分）を充てることもできます。

## 推奨評価方法

- 実行再現（40%）: 手順通り動作させられるか
- 理解説明（40%）: なぜ `allow/deny` になるか説明できるか
- 改善提案（20%）: Phase 2/3に向けた提案の妥当性

## レポート最小要件

- 実行環境（OS、Dockerバージョン）
- 実行コマンドと出力ログ
- `allow` ケースと `deny` ケースの比較
- 改善提案（最低1件）

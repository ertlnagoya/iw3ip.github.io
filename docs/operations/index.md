# 困ったとき

演習の途中で手順どおりに動かないとき、ないしは進め方に迷ったときに読む章です。受講者と TA を主な読者としています。

- [トラブルシュート](troubleshooting.md): 症状に近い項目を探し、確認点と対応を順に確認します。各ハンズオンのページの末尾にある「トラブル時」もあわせて確認してください
- [FAQ](faq.md): どのサンプルから始めるか、実機やスマホが無くても進められるか、Part・Phase・Stage の違いといった、進め方と位置付けに関する質問

授業の組み立てや進行の時間配分は、講師・TA 向けの「授業で使う」([授業ガイド](../foundations/course-guide.md)、[講師進行ガイド](facilitator-guide.md)) にまとめています。仕組みや設計の判断の理由は [設計](../design/index.md) の章で説明しています。

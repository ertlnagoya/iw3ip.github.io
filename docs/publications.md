# 論文

IW3IP に関する発表論文です。サイト内の基礎章とハンズオンを終えたあとの発展学習に利用してください。

ブロックチェーンを用いた分散型の IoT データ流通の枠組みと、その上でデータの加工を柔軟に行うエッジ処理は、[1] で提案しています。データの提供者と利用者を SSI（Self-Sovereign Identity）で認証する方式と、PostgreSQL と IPFS で管理するメタデータを条件で検索する方式は、[2] で提案しています。本サイトの SSI を使うハンズオン（[データ提供者の認証 (Consent VC / Stage 1)](hands-on/ha-ssi-wallet.md) など）は、[2] の認証方式に関連します。[3] は、同じくブロックチェーンを用いて、個人健康記録（PHR）と電子カルテ（EMR）を、楕円曲線暗号、ゼロ知識証明、アクセス制御によって共有するモデルを提案しています。
